快速上手

  1. 打开 设置，选择预设（preset）和缩放比例。
  2. 添加 监视文件夹，让应用能够发现存档或模拟器目录。
  3. 先启动一次游戏，使其存档文件夹或本地成就文件生成。
  4. 让监视器尽可能自动创建配置，或者手动创建配置。
  5. 选中该配置并选择语言，即可查看成就、进度和游戏时长。
  6. 可选：为当前激活的配置静音进度通知。

从命令行打开已有配置

向已安装或已解包的可执行文件同时传入 AppID 和平台，即可直接打开一个已有配置： 

Achievements.exe --appid=239140/steam
Achievements.exe --appid=239140 --platform=steam
  • 两种格式都支持且等价。
  • 如果 Achievements 已在运行，则会打开已有实例并跳转到匹配的配置。
  • AppID 和平台必须与某个已存在的配置完全匹配。这些参数不会生成配置，也不会启动游戏。
  • 支持的平台值与下方 配置 JSON 参考 中列出的值相同。

首次运行引导

  • 首次运行时，启动过程可能暂停，并在完整自动扫描开始前显示文件夹选择弹窗。
  • 应用会搜索已知的成就特征文件，例如 achievements.json、 achievements.ini、stats.bin、奖杯文件以及模拟器进度文件。
  • 开始自动配置 会保持所选文件夹为激活状态，并静音未勾选的已发现文件夹。
  • 跳过并全部静音 会立即继续启动，并静音已发现的或默认的自动配置根目录。
  • 引导待处理期间，文件夹监视器和启动自动配置扫描会保持推迟状态，以避免生成不需要的配置。
  • 引导状态存储在 %APPDATA%\Achievements\preferences.json 中， 使用 autoConfigOnboardingCompleted、 autoConfigOnboardingVersion 和 autoConfigOnboardingCompletedAt 三个字段。
  • 若启动仍被阻塞但弹窗不可见，请使用托盘操作 恢复启动（全部静音）。

手动配置

使用以下字段创建配置：

  • 名称：你偏好的标识符。
  • AppID：该游戏使用的 Steam AppID 或文件夹标识符。
  • 配置路径：包含 achievements.json 和 img/ 的文件夹，留空则自动生成。
  • 存档路径：进度或存档数据所在位置。
  • 可执行文件 与 参数：可选的启动设置。
  • 进程名：可选，用于明确指定要监控的进程名。

名称在保存前会被净化处理，磁盘上和游戏时长统计中使用的都是净化后的名称。

配置 JSON 参考

  • appid —— 游戏 ID。
  • platform —— 取值之一：steam、steam-official、uplay、 ubisoft-official、ea-official、epic、epic-official、gog、 gog-official、xbox-pc、retroachievements、xenia、rpcs3、shadps4、 markerpatch、madnesspatch、xlivelessness。
  • config_path —— 包含 achievements.json 和图片资源的文件夹。
  • save_path —— 包含本地进度或存档数据的文件夹。
  • process_name —— 用于进程追踪的可执行文件名。
  • executable / arguments —— 可选的启动元数据。

如果 config_path 指向自定义位置，则成就表重新生成和清理操作不会覆盖该文件夹。

自动配置

当应用能够定期扫描监视文件夹时，自动配置的效果最好。

  1. 添加一个或多个包含模拟器数据、存档文件夹或启动器缓存的 监视文件夹。
  2. 应用会检测 AppID 并判定平台。
  3. 当数据源可用时，它会获取游戏名称、成就表、成就数据和图片。
  4. 然后自动生成配置。

默认监视文件夹

  • %PUBLIC%\Documents\Steam\CODEX
  • %PUBLIC%\Documents\Steam\RUNE
  • %PUBLIC%\Documents\OnlineFix
  • %PUBLIC%\Documents\EMPRESS
  • %APPDATA%\Goldberg SteamEmu Saves
  • %APPDATA%\Goldberg UplayEmu Saves
  • %APPDATA%\R1 UplayEmu Saves
  • %APPDATA%\GSE Saves
  • %APPDATA%\EMPRESS
  • %LOCALAPPDATA%\anadius\LSX emu\achievement_watcher
  • %APPDATA%\Steam\CODEX
  • %APPDATA%\SmartSteamEmu
  • %LOCALAPPDATA%\SKIDROW
  • %LOCALAPPDATA%\UniverseLAN

Goldberg UplayEmu Saves 和 R1 UplayEmu Saves 使用 Uplay 到 Steam 的映射， 同时保留原始的 Uplay AppID 和成就表存储。 %LOCALAPPDATA%\UniverseLAN 被视为严格的 GOG 根目录； 其目录结构请参见 UniverseLAN 平台指南。

文件夹重新扫描与黑名单

  • 文件夹 - 重新扫描 会打开一个包含当前激活监视文件夹的弹窗。 可用 全选 或 全不选，然后只扫描选中的根目录。
  • 已忽略的文件夹和已忽略的嵌套文件夹，即使其父级监视文件夹被选中，也仍然排除在外。
  • 重新扫描不会清空文件夹忽略列表或 AppID 黑名单。
  • 忽略某个已配置游戏时使用的是其 AppID 与平台身份， 因此同一 AppID 在其他平台上仍可保持激活。
  • 设置 - 高级 - 添加黑名单 AppID 支持一次添加多个 AppID，包括被错误识别的用户 ID。 多个值之间用逗号、空格或换行分隔。
  • 重置黑名单 会移除全局及平台专属的黑名单条目， 但不会移除监视文件夹，也不会重新扫描无关的配置。

Steam 模拟器进度文件

  • Online-Fix 的解锁状态来自 Achievements.ini。 Stats.ini 仅提供已映射的成就进度和进度通知。
  • 空的 Online-Fix Stats.ini 仍会保持监控。它不会解锁成就， 也不会清空当前缓存；后续写入的统计值会被应用。
  • Tenoke 从 user_stats.ini 读取解锁状态和统计数据。 统计值会在可用时通过成就的 operand1 值映射到成就表进度规则。
  • 统计数据本身永远不会解锁成就。模拟器的成就状态始终是唯一依据。

Steam API 密钥行为

当设置中已保存密钥时，自动配置会优先使用 Steam Web API。

  • 有密钥：应用在可能的情况下使用 Steam Web API 获取成就表和元数据。
  • 无密钥：回退到 SteamDB、SteamHunters 和 Exophase， 在可用时用于补充语言信息。
  • 可用时使用的数据源包括：Steam Web API、SteamDB、SteamHunters、 Exophase、GOG 和 Epic。
