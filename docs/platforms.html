平台

官方启动器集成、在线服务以及原生客户端流程。

Steam Official 支持

  1. 将 C:\Program Files (x86)\Steam\appcache\stats 添加到 监视文件夹。
  2. 通过 Steam 启动并游玩游戏。
  3. 应用会读取 Steam 的本地统计文件，解析成就表和图片， 自动生成配置，并追踪解锁状态。

Epic Games 启动器支持

  1. 在 设置 - 高级 中连接 Epic 账号， 并使用 导入游戏库。
  2. 已拥有且带成就的游戏会被自动导入为 epic-official 配置。
  3. 本地清单文件用于解析安装路径、可执行文件和进程名。
  4. 轮询仅针对检测到的正在运行的 Epic 游戏，或所选的 Epic Official 配置执行。

商店图片优先通过 Epic 元数据解析，仅在必要时才回退到 SteamGridDB。

对于使用 artifact 或 AppID 而非命名空间的 Epic 模拟文件夹， 成就表生成会先解析相关的目录项和命名空间，再继续走正常的 Epic 成就表流程。

Xbox PC（微软 / Xbox Network）支持

  1. 打开 设置 - 高级，在 Xbox PC（微软 / Xbox Network） 下选择 连接 Xbox。
  2. 使用 Windows Xbox 应用所用的账号，通过微软 OAuth 登录。
  3. 使用 导入 Xbox PC。应用会从 Xbox 档案中读取支持成就的 Windows/PC 游戏，扫描本地 XboxGames 和已打包的 GDK 安装， 生成 xbox-pc 配置和成就表， 并在可用时关联本地可执行文件或 AUMID 信息。
  4. 所选 Xbox PC 配置的成就状态直接从 Xbox Network 刷新， 带请求限流和本地缓存回退。

重要说明

  • 排除仅限 Xbox 主机的历史记录。只有当 Xbox 报告了 Windows/PC 设备， 或其 Title ID 与本地已安装游戏匹配时，才会导入该游戏。
  • 委托给 EA App、Ubisoft Connect 或其他启动器的游戏， 在 PC 上可能无法提供 Xbox 成就。
  • 微软刷新令牌和 Xbox XSTS 会话以加密方式存储。 应用从不索取或存储微软账户密码或 Entra 客户端密钥。
  • 实验性认证路由使用的是 OpenXbox Xbox-WebAPI 项目 公开的桌面 OAuth 身份。该身份不归 Achievements 项目所有； 微软可能会限制或撤销其使用，Xbox Network 直连端点也可能拒绝请求。
  • xbox-pc 配置是自动生成的，不应手动创建。

RetroAchievements 支持

  1. 打开 设置 - 高级，输入 RetroAchievements 控制面板中的用户名和 Web API 密钥。
  2. 选择 连接，然后 导入游戏库。 应用会为账号历史创建独立的 retroachievements 配置和成就表。
  3. 在面板中选择一个 RetroAchievements 配置以启动其 API 轮询器。 初始缓存状态之后收到的新解锁会生成通知。

重要说明

  • 此集成仅使用只读的 RetroAchievements Web API。 它不会扫描模拟器、ROM、进程或本地游戏文件夹。
  • Web API 密钥通过 Electron safeStorage 存储， 不会以明文写入偏好设置或配置文件。
  • 轮询仅针对在界面中明确选择的 RetroAchievements 配置运行。 当选择其他平台或配置，或断开账号时停止。
  • 初始导入会静默初始化已有解锁， 避免历史解锁造成通知轰炸。

GOG Galaxy 启动器支持

  1. 安装并登录 GOG Galaxy。
  2. 将 %LOCALAPPDATA%\GOG.com\Galaxy\Applications 添加到 监视文件夹。
  3. 至少通过 GOG Galaxy 启动并游玩一次游戏。
  4. 应用会解析本地的 client id 到 product id 映射，监视 gameplay.db，生成 gog-official 配置，构建 achievements.json 和 achievementpercentages.json， 然后监控后续变化。

重要说明

  • gog-official 是自动生成的，不应手动创建。
  • 只有当 gameplay.db 存在且成就表已填充并稳定之后， 才会创建配置。
  • 如果某游戏只有 Storage 数据而没有 Gameplay\<userId>\gameplay.db， 应用会检测到安装路径，但会等待 gameplay 数据库生成后再创建配置。
  • 运行时进度从 gameplay.db 读取， 尽管保存的配置指向具体的 gameplay 文件夹。

Ubisoft Connect 启动器支持

  1. 安装并登录 Ubisoft Connect。
  2. 手动将 %LOCALAPPDATA%\Ubisoft Game Launcher\spool 添加到 监视文件夹。
  3. 至少启动并游玩一次游戏，使本地 spool 或缓存文件生成。
  4. 应用会检测 spool\<userId>\<productId>.spool， 从育碧本地成就缓存生成本地成就表、稀有度附加文件和图片， 然后自动创建 ubisoft-official 配置。

重要说明

  • ubisoft-official 由手动监视的 spool 根目录生成， 不应手动创建。
  • 配置生成会等待 spool 文件和本地成就存档都可用之后才进行。
  • 配置指向具体的 spool\<userId> 文件夹， 而运行时进度从 <productId>.spool 读取。

EA Desktop 启动器支持

  1. 安装并登录 EA Desktop。
  2. 手动将 %LOCALAPPDATA%\Electronic Arts\EA Desktop\Logs 添加到 监视文件夹。
  3. 至少启动并游玩一次游戏，使 EADesktopVerbose.log 中包含成就集记录。
  4. 应用会生成本地成就表和图片，创建 ea-official 配置， 并监控后续的日志变化。

重要说明

  • ea-official 由手动监视的 EA Desktop 日志根目录生成， 不应手动创建。
  • 配置生成会等待 EA Desktop 记录下该游戏的完整成就集之后才进行。
  • 配置指向 EA Desktop 的 Logs 文件夹； 运行时进度从 EADesktopVerbose.log 读取。
  • 应用同时也会读取 EADesktopVerbose.bak， 避免详细日志轮转时丢失成就事件。

模拟器

Goldberg、Uplay、GOG、Epic 和 EA 的辅助工具生成方式。

GSE

  1. 下载并解压 generate_emu_config。
  2. 在该文件夹中创建 my_login.txt，按如下格式保存你的 Steam 账号： 
    username
password
  3. 运行 generate_emu_config.exe_user.exe 并输入目标 Steam AppID。
  4. 如果该账号启用了二次验证（2FA），按提示完成验证码输入。
  5. 将游戏原始的 steam_api64.dll 重命名为 steam_api64.dll.bak。
  6. 将 _OUTPUT\appid 中的全部内容复制到重命名后的 DLL 旁边。
  7. 运行一次 gse_generate_interfaces.exe，然后启动游戏。
  8. 在 Achievements 中，%APPDATA%\GSE Saves 是默认监视文件夹， 因此 AppID 可被检测到，配置也能自动生成。

Achievement Enabler（作者 Roschach96）

  1. 下载最新的 Achievement Enabler 版本，并将 ZIP 解压到一个独立的工作文件夹。
  2. 对于 Steam 和 Ubisoft，将 dummy_account.txt.example 重命名为 dummy_account.txt，并填入一个一次性 Steam 账号的凭据。 GOG 和 Epic 不需要此文件。
  3. 请备份解压后的文件。该工具在完成后会从游戏文件夹中移除其脚本相关文件。
  4. 将解压出的所有脚本文件和文件夹复制到游戏主文件夹。
  5. 运行 _Achievement_Enabler.bat 并按提示操作。 这是唯一需要启动的脚本。

账号文件示例

username
password

统一设置的工作原理

  • 脚本会根据游戏文件夹中的文件检测合适的适配器（adapter）。 当未检测到其他适配器加载器时，会回退使用 Steam ColdClient。
  • Steam 和 Ubisoft 需要额外的适配器资源文件。 请使用当前 Achievement Enabler 版本提供的文件和版本信息。
  • 该设置会执行破解状态检查、查找或确认 Steam AppID、获取成就数据、 检查启动参数、生成平台配置、将游戏导出到 Achievements、 创建桌面快捷方式，并清理其临时脚本文件。
  • 对于 Ubisoft Uplay R1/R2，相应的加载器和 INI 文件必须已存在。 若缺失，设置会中止并提示先应用所需的适配器文件再重新运行。
  • 对于 Steam ColdClient，按提示选择使用干净的 Steam 文件或 voices38 版本流程。若在设置前 voices38.dll 已存在，安全检查会中止并提示先干净重装再重试。
  • 生成的 JokerVerse 配置包含检测到的可执行文件和进程信息， 以便 Achievements 用于启动、选择和游戏时长监控。

Uplay Goldberg 方法

  1. 下载 Uplay.rar。
  2. 解压 Uplay.rar，并将 Uplay 文件夹复制到 generate_emu_config 文件夹中。
  3. 在该文件夹中创建 my_login.txt，按如下格式保存你的 Steam 账号： 
    username
password
  4. 打开 generate_uplay_achievements_from_steam.bat 文件， 使用该育碧游戏的 Steam AppID 运行它。
  5. 这会为该 Uplay 游戏生成 achievements_schema.json。
  6. 将 demde 版本的 Goldberg Uplay R1 或 R2 文件以及 achievements_schema.json 复制到游戏文件夹， 替换原始的 Uplay DLL。请检查 Uplay R1/R2 的 ini 文件， 确认已启用 Achievements 配置。
  7. 若游戏使用 r2 版本，启动游戏。Achievements 可从默认监视文件夹 %APPDATA%\Goldberg UplayEmu Saves 自动检测到它。
  8. 若游戏使用 r1 版本，启动游戏。Achievements 可从默认监视文件夹 %APPDATA%\R1 UplayEmu Saves 自动检测到它。

Uplay LumaPlay

x86 安装

  1. 将 LumaPlay_x86.exe 和 LumaPlayFiles 文件夹复制到游戏文件夹。
  2. 从 C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher 复制原始的 uplay_r1.dll 到 LumaPlayFiles， 并重命名为 UbiAPI.dll。
  3. 在 LumaPlay.ini 中更新可执行文件名、appid 及其他设置。
  4. 继续按下面的 x64 成就配置步骤操作。

x64 安装

  1. 将 LumaPlay_x64.exe 和 LumaPlayFiles 复制到游戏文件夹。
  2. 从育碧启动器复制 uplay_r164.dll 到 LumaPlayFiles，并重命名为 UbiAPI.dll。
  3. 在 LumaPlay.ini 中更新可执行文件名、appid 及其他设置。
  4. 配置 [Achievements] 分区，例如： 
    [Achievements]
GenerateAchievementReportOnExit = 1
NumberOfAchievements = 50
UplayGameID = 1803

Achievement_1 = The Spark - Complete the game intro by liberating Dutch's island (Solo Campaign only).
Achievement_2 = You Are Wrath - Be deemed the Sin of Wrath (Solo Campaign only).
Achievement_3 = Special Delivery - Ensure a baby's safe passage into this world (Solo Campaign only).
Achievement_4 = Only You - Successfully complete the First Trial (Solo Campaign only).
...
  5. 在 Achievements 中启用 设置 - 文件夹 - 启用 LumaPlay 监视器。
  6. 通过 LumaPlay 启动游戏。应用会扫描 HKCU\SOFTWARE\LumaPlay 下的成就条目，检测 AppID， 并在可能时生成带 emu=lumaplay 的匹配 uplay 配置。

重要说明

  • 启用期间，原生注册表变更事件会触发成就刷新和通知， 无需反复轮询整个注册表树。
  • LumaPlay 注册表监视器仅限 Windows，且仅在启用该选项时启动。
  • 禁用它会停止 LumaPlay 注册表监控，但不会禁用监视文件夹监控或常规进程检测。

请确保游戏主文件夹中的 uplay_r1_loader(64).dll 尽可能接近原始文件。

XLiveLessNess 支持

  1. 为受支持的 Games for Windows - LIVE 游戏安装并配置 XLiveLessNess。 若模拟器需要创建其档案数据，则先启动一次游戏。
  2. 在 设置 - 文件夹 中添加已安装的游戏目录。 可以添加游戏根目录，也可以添加在受支持的发现深度内包含所需文件的父目录。
  3. 确认某个可执行文件目录中同时包含 xlive.dll、 <game>.exe 和匹配的 <game>.exe.cfg。 若文件夹是在这些文件安装之前添加的，请使用 文件夹 - 重新扫描。
  4. 应用会从 <game>.exe.cfg 读取 Title ID， 并从可执行文件内嵌的 SPAFILE 资源获取本地化的成就名称和描述、 玩家分数（Gamerscore）以及图片。
  5. 生成 xlivelessness 本地配置和成就表。 可执行文件名和进程名会被保存，用于启动、进程检测、自动选择和游戏时长统计。
  6. 解锁状态从 XLiveLessNess\profile\title\<TITLEID> 下每个匹配的 <profile>\achievements.dat 读取。

预期的游戏侧目录结构

<游戏文件夹>\
└─ <可执行文件目录>\
   ├─ xlive.dll
   ├─ <game>.exe
   └─ <game>.exe.cfg

重要说明

  • 发现和 SPAFILE/成就表处理均为异步执行，并显示在标准的生成进度条中。
  • 首次生成配置时不需要 achievements.dat。 自适应监视器会在 XLiveLessNess 创建档案或 title 路径后挂载。
  • 默认的 %LOCALAPPDATA%\XLiveLessNess 根目录和 游戏本地的 XLiveLessNess 根目录都会被自适应监控。 也可以在 设置 - 文件夹 中添加自定义存储根目录。
  • 当进程命令行检测可用时，会解析 -xllnconfig=<path>， 并自动将其所在目录添加为另一个状态根目录。
  • 同一 Title ID 的多个可执行文件会作为一个配置中的进程名备选保留。 各档案保留独立基线，以避免切换用户时产生虚假通知。
  • 当内嵌的 SPAFILE 包含相应本地化时，成就表语言遵循 设置 - 高级 - 成就表语言 中的选择。
  • 应用只读取已安装的可执行文件、title 配置和成就状态， 不会修改游戏或模拟器数据。

GOG UniverseLAN

当前全局存储布局

  1. 安装并配置 UniverseLAN，使其游戏数据存储在 %LOCALAPPDATA%\UniverseLAN 下。
  2. 将每个游戏放在一个直接的 ProductID 目录中： %LOCALAPPDATA%\UniverseLAN\<ProductID>。
  3. 运行时进度必须存在于 %LOCALAPPDATA%\UniverseLAN\<ProductID>\UniverseLANData\Achievements.ini。
  4. 默认监视根目录被视为严格的 GOG 数据源。应用会将每个直接的 ProductID 目录映射为一个 GOG 配置，并监控其 Achievements.ini 文件。

旧版游戏本地设置

已有的游戏本地 UniverseLAN 安装仍受支持。 如果游戏在旧版布局下已正常工作，可继续沿用。

  1. 确认游戏使用的 galaxy64.dll 版本，下载匹配的 UniverseLAN 构建，并解压到游戏文件夹。
  2. 运行 UniverseLANServer64.exe 并保持其开启，然后启动游戏可执行文件。
  3. 旧版安装会在 <gamefolder>\UniverseLANData\Achievements.ini 中生成局部成就数据。
  4. 将游戏文件夹添加到 监视文件夹。 旧版发现机制继续使用 UniverseLAN.ini 来识别并生成配置。

NemirtingasEpicEmu

  1. 打开 egdata.app 并复制该游戏的 Namespace（命名空间）。
  2. 解压并运行 fetch_epic_achievements.bat。
  3. 将生成的 achievements_db.json 和成就图片复制到 EOSSDK-Win64-Shipping.dll 旁边的 nepice_settings 中。
  4. 编辑 NemirtingasEpicEmu.json，将 AppId 替换为该 Namespace。
  5. 在游戏可执行文件旁边创建一个 Launcher.txt 文件， 写入以下内容，然后将文件重命名为 .bat： 
    @echo off
cd /d "%~dp0"
start /b "Alan Wake 2" "AlanWake2.exe" -AUTH_LOGIN=unused -AUTH_PASSWORD=cdcdcdcdcdcdcdcdcdcdcdcdcdcdcdcd -AUTH_TYPE=exchangecode -epicapp=c4763f236d08423eb47b4c3008779c84 -epicenv=Prod -EpicPortal -epicusername="Player" -epicuserid=4340353b292a150000e7d9b5a47b6343 -epicsandboxid=c4763f236d08423eb47b4c3008779c84 -epiclocale=en
    按目标游戏修改其中的值： Alan Wake 2 是窗口标题， AlanWake2.exe 是游戏可执行文件名， epicapp 与 epicsandboxid 必须使用从 egdata.app 获取的 Namespace。
  6. 将 %APPDATA%\NemirtingasEpicEmu 添加到 监视文件夹。应用可检测到 Namespace 并自动生成配置。

anadius Origin/EA Emu

  1. 获取 anadius Origin 模拟器工具，包括 example config + tools.7z 和 get_token.exe。
  2. 安装 Tampermonkey 浏览器扩展。
  3. 将 example config + tools 中的 Origin Helper.user.js 拖入 Tampermonkey。
  4. 打开 ea.com，点击左上区域的 Origin Helper，然后点击 Generate emulator config。
  5. 选择游戏的 __Installer\installerdata.xml。
  6. 勾选以下选项：
    • Use default port
    • Add Content section
    • Add placeholder Entitlement
    • Add achievements
    然后点击 Continue。
  7. 在新标签页打开 https://isthereanydeal.com/ 并搜索该游戏。
  8. 打开游戏页面，滚动到或搜索 Products， 找到 EA Store 条目，复制 Origin.OFR id。
  9. 将该 id 粘贴到 Origin Helper 的输入框中， 然后点击 Continue。
  10. 运行 EA App 并登录，然后运行 get_token.exe。
  11. 复制 get_token.exe 输出的四行内容： access token（访问令牌）、username（用户名）、user ID（用户 ID）和 persona ID（角色 ID）。将它们粘贴到 Origin Helper 中并点击 Continue。
  12. 在下一个界面，在新标签页中打开 SteamDB 链接，进入 Achievements 页面，按 F12， 然后在控制台中粘贴： 
    copy(document.documentElement.outerHTML)
  13. 将复制的 HTML 粘贴到 Origin Helper 的输入框中。 待成就显示为 Green Fields 后，点击 Continue。
  14. 保存 anadius.cfg，并将它与 anadius32.dll 或 anadius64.dll 一起复制到 game.exe 旁边的游戏文件夹中。
  15. 将 %LOCALAPPDATA%\anadius\LSX emu\achievement_watcher 添加到 监视文件夹。应用可检测到 AppID 并生成配置。

主机模拟器

Xenia、RPCS3 和 ShadPS4 的原生模拟器流程。

Xenia-Canary 支持

  1. 打开 Xenia 并创建一个用户配置文件。
  2. 将生成的 Xenia\Content\xxxxxx\xxxx\xxxx\xxxxxx 路径添加到 监视文件夹。
  3. 启动并游玩游戏。
  4. 应用会读取生成的文件，获取游戏名称、成就表和图片， 自动生成配置，并在解锁新成就时显示通知。

RPCS3 支持

  1. 将 RPCS3\dev_hdd0\home\xxxxxxx\trophy 添加到 监视文件夹。
  2. 启动并游玩游戏。
  3. 应用会读取奖杯文件，获取成就表和图片，自动生成配置， 并在解锁时显示通知。

ShadPS4 支持

  1. 添加 ShadPS4 根文件夹：%APPDATA%\shadPS4。
  2. 启动并游玩游戏，使 ShadPS4 创建奖杯表和用户进度文件。
  3. 应用从 %APPDATA%\shadPS4\trophy\<NPWR>\Xml 读取成就表， 从 %APPDATA%\shadPS4\trophy\<NPWR>\Icons 复制图标， 并从 %APPDATA%\shadPS4\home\<userId>\trophy\<NPWR>.xml 读取进度。
  4. 当映射关系可用时，会使用本地 ShadPS4 日志或旧版数据将 NPWR 奖杯 ID 映射到 CUSA 游戏 ID。
  5. 所选游戏的所有本地用户进度 XML 文件都会被监控， 因此用户切换会被自动检测到。

重要说明

  • 当现代布局与旧版布局同时存在时，优先使用现代 ShadPS4 存储。
  • %APPDATA%\shadPS4\game_data\<CUSA>\TrophyFiles\trophy00 下的旧版存储仍受支持。
  • 如果存在多个用户，成就缓存按用户隔离。
