个性化

面板、浮层、偏好设置与运行时路径。

本页汇总配置完成后影响应用行为的各项用户可控设置。

面板

  • 通过 显示面板 打开游戏网格。
  • 使用搜索快速筛选游戏。
  • 按平台筛选，并按名称、进度或最近更新时间排序。
  • 点击游戏卡片以加载其配置。
  • 使用 Ctrl + 点击 或卡片右键菜单选择多个游戏， 然后从操作栏中忽略、删除或清除选择。
  • 启用 显示已拉黑的游戏 可查看并恢复被忽略的游戏。
  • 对已配置可执行文件的游戏使用播放按钮。
  • 后台轮询可在游戏进程启动时自动选中该游戏。
  • Esc 或关闭按钮会恢复主界面与输入状态。

个性化

  • 选择通知预设和屏幕位置。
  • 选择 Windows 原生 可使用 Windows Toast 通知， 替代动画预设。
  • 选择通知音效和语言。
  • 从 设置 - 高级 - 成就表语言 中选择要生成哪些成就表语言。
  • 在 75% 到 200% 之间调整界面缩放。
  • 调整成就持续时间和音量。
  • 在可用时切换显示隐藏描述。
  • 启用关闭到托盘。
  • 配置浮层快捷键和交互键。
  • 配置 通知点击动作，点击后在不可聚焦的浮层或主应用中 打开对应的成就。打开主应用会将焦点从游戏移开。
  • 存储在操作中心的 Windows 原生通知保留独立的导航路由， 使每条可用通知都能打开各自的成就。
  • 从 设置 → 高级 → 渲染 启用或禁用浮层手柄支持。
  • 启用或禁用成就截图、成就录制、进度通知、游戏时长通知以及启动行为。
  • 可为当前激活的游戏配置单独静音进度通知。
  • 使用 随 Windows 启动 为当前可执行文件创建或移除 任务计划程序条目。
  • 禁用原生进程监视器可改用基于 ps-list 的可执行文件名回退检测。 回退模式下无法获取命令行参数。

Xbox Game Bar 通知

  • 可选的 Xbox Game Bar 伴生组件 Achievements Overlay by JokerVerse 可以发送原生 Game Bar 通知。
  • 推送内容包括成就解锁、稀有度或白金元数据、点击跳转， 以及 当前 / 最大值 • 百分比 格式的文本进度。
  • 该伴生组件是可选的。若未安装或未连接， Electron 应用仍可独立运行并使用已配置的通知回退方案。

成就录制

  • 启用成就录制后，会在每次解锁前后保存一段短视频片段。
  • 选择 30 或 60 FPS。
  • 选择 10 至 30 秒的总时长，在解锁前后平均分配。
  • 录制捕获 Windows 默认输出混音。若系统音频不可用， 录制会安全回退为仅视频；不捕获麦克风输入。
  • 可选的 GPU HDR 转 SDR 转换可让 H.264/MP4 片段兼容标准 SDR 播放器。

更新日志

  • 设置 - 更新日志 列出 GitHub 上的发布版本， 包含版本号、发布类型、发布日期和发布说明。
  • 发布数据缓存 30 分钟。刷新 会请求当前数据， 而最后一次有效缓存仍可在离线时使用。
  • 发布链接会在默认浏览器中打开 GitHub。远程发布文本按纯文本显示， 不会作为 HTML 执行。

实时日志

  • 设置 - 日志 列出已知的应用日志， 并会发现日志目录中额外的 .log 文件。
  • 所选文件会被实时跟踪，并在文件替换、截断和常规日志轮转时保持同步。
  • 搜索以及 DEBUG、INFO、 WARN、ERROR 筛选只影响显示的行。
  • 暂停 会暂停界面更新， 清除视图 只清除内存中的视图， 打开日志文件夹 会打开原始文件。
  • 初始视图最多包含 1,000 行最近的记录，界面最多保留 2,000 行。 监控仅在日志标签页处于活动状态时运行。
  • 日志中可能包含本地路径或账号标识符。公开分享前请先检查。

键盘与手柄要点

  • 手柄支持 包含面板介绍与手柄导航操作。
  • 多平台支持 V2 + 浮层手柄支持 还包含浮层手柄支持的操作流程。

全局

设置：F1 / Ctrl+O。面板： F2 / Ctrl+D。游玩：P / Ctrl+Enter。

浮层

使用已配置的浮层快捷键切换显示。使用已配置的交互键切换交互模式。

浮层手柄模式

Xbox：View + Menu 切换浮层，按住 LB + RB 进入控制模式。PlayStation 使用 Share + Options 和 L1 + R1。

主界面

用 Ctrl+N 新建配置。用 F3 切换选项面板。 用方向键或手柄方向键（D-pad）导航。
